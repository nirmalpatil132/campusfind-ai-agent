Lost something on campus? Found something?

CampusFind AI is an AI agent that takes your lost or found report in plain language, asks for missing details, saves it, and searches for potentially matching reports. A human admin verifies every claim before an item is handed over.

  1. Tell the agent what you lost or found, e.g. "I lost my black HP laptop bag in CSE block yesterday".
  2. The agent asks one question at a time, shows a summary and saves only after you say yes.
  3. The matching engine scores reports by category, colour, place, time and brand.
  4. The owner answers a private verification question. The admin verifies and marks the item returned.

Runs on a free local AI model (Ollama) when available, otherwise on a rule-based engine, which is clearly labelled. No paid AI API is used.

A candidate is not a confirmed match. Answer the verification question; an admin then compares your answer with the finder's private note before anything is handed over.
